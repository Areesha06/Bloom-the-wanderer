# Traps & Props (free sampler)

6 pixel-art dungeon traps and interactive props, generated from code,
16 pixels to a tile, lit from the upper left like the rest of the LumioLab
packs.

- **loop** pieces cycle (a saw spins, a crusher slams, a torch flickers):
  frame 8 is frame 0, so they loop with no jump.
- **once** pieces play once when triggered (a chest opens, a crate smashes, a
  door swings, a platform crumbles). The JSON says `"loop": false`. Frame 0
  is the resting state.
- `*_tile` pieces repeat seamlessly (floors and bridges sideways, walls both
  ways, ladders up, lava and acid both ways *and* in time).
- `pendulum_axe` and `crusher` are anchored at the TOP centre (hang them from
  the ceiling); `spiked_mace` at its centre (the pivot). Everything else
  stands on its bottom edge.
- Timing notes: `arrow_trap` flashes on frame 1 (spawn `arrow_projectile`
  then); `crusher` hits the floor on frame 4; `spikes_retract` is dangerous on
  frames 3-5; `fire_jet` burns on frames 2-5.

Each piece is a PNG strip with a `.sheet.json` beside it: cell size, frame
count, fps, loop flag and every frame's rect. `rect` y is measured from the
BOTTOM of the image (Unity's convention); padding 2 px.

## Use

- Unity: Sprite Mode Multiple, slice by cell size, Filter Point, Compression
  None, 16 pixels per unit.
- Godot: AnimatedSprite2D / SpriteFrames from the strip, hframes = frames.
- Anything else: the cells are a regular grid.
